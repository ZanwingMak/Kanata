# 01 · 需求文档（PRD）

> 阅读约定：
> - 优先级 **P0**=不做则产品不成立 / **P1**=体验必需 / **P2**=增强。
> - 平台列 `I`=iOS `P`=iPadOS `T`=tvOS `W`=Web `G`=网关；`—` 表示不适用。
> - 每条需求都必须有可判定的验收标准（AC）。测试用例在 `05-测试文档.md` 中按 ID 反查。
