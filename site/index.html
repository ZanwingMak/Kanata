A FEW THINGS TO KNOW

开始之前，你可能想问。

还有问题？在 GitHub 告诉我们 ↗
Kanata 自带影视资源吗？+

Kanata 是自有媒体播放器，不提供影视资源。请连接自己有权观看的本地文件、NAS 或媒体服务器。官网中的播放画面为体验示意。

现在可以在哪里下载？+

目前通过 TestFlight 公开测试分发，尚未作为正式版本上架 App Store。需要 iOS / iPadOS 17.0 或 tvOS 17.0 及以上；测试名额和版本可用性以 TestFlight 页面为准。

弹幕来源需要配置吗？+

可以导入本地弹幕，也可以根据应用设置配置在线来源或自托管弹幕网关。弹弹play 渠道需要填写自己的开放平台凭据。平台来源可用性与匹配结果受第三方接口影响，某个来源不可用时仍可继续播放视频。具体配置方式见 仓库使用说明。

账号凭证和观看进度存在哪里？+

Apple 应用把密码、令牌与平台 Cookie 存在本机 Keychain。iCloud 同步媒体库索引、观看进度、收藏及相关偏好，不上传这些敏感凭证、视频文件或弹幕缓存。本官网不使用分析追踪脚本，也不收集媒体服务器账号。

为什么有些文件可能无法播放？+

Kanata 提供原生与通用解码内核，媒体服务器来源还支持兼容流。实际兼容性取决于设备、编码、网络与服务器配置。WebDAV 来源本身没有服务端转码能力；遇到问题可以提交设备型号、文件编码和脱敏后的错误信息。

如何反馈公测问题或参与开发？+

可以通过 TestFlight 发送反馈，也可以在 GitHub Issues 提交问题。附上系统版本、复现步骤与截图会更方便定位；请不要公开密码、令牌或私有媒体地址。源代码和浏览器播放器也在同一仓库中。
